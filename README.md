# 🐍 Изгиб Питона (Snake Game)

Классическая игра «Змейка», реализованная на Python с использованием библиотеки **Pygame** и принципов **объектно-ориентированного программирования (ООП)**. 

Проект написан в рамках учебного курса (например, Яндекс Практикум) с упором на чистоту кода, архитектуру и соответствие стандарту PEP 8.

## ✨ Особенности реализации

- **ООП-архитектура:** Логика разделена на базовый класс `GameObject` и наследуемые от него классы `Snake` и `Apple`.
- **Проход сквозь стены:** Змейка телепортируется на противоположную сторону поля при выходе за границы (используется оператор `%`).
- **Оптимизированная отрисовка:** Реализовано «затирание следа» хвоста, что предотвращает мерцание и артефакты на экране.
- **Надёжность:** Добавлены значения по умолчанию (`None`) в конструкторы для корректной работы модульных тестов (pytest).
- **Документация:** Все классы и методы покрыты информативными docstrings.

## 🛠 Технологический стек

- **Python 3.10+**
- **Pygame 2.x**
- **pytest** (для автоматического тестирования)
